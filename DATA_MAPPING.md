# Data mapping (site field → source)

All displayed numbers are read from JSON generated by `scripts/build_data.py` (`npm run data`) from the **final, unmodified** competition outputs in `../outputs/`. Nothing is recomputed except the items marked *derived*. `build_data.py` asserts that the ranks, IDs and order in `FINAL_top10_*.csv` equal `SUBMISSION_rankings.csv`, and records the first 16 hex chars of the SHA-256 of the submitted CSV and PDF (`src/data/provenance.json`, shown in the footer).

| Site element | JSON | Source file / column |
|---|---|---|
| Rankings, names, IDs, rank | `top10.json` | `outputs/SUBMISSION_rankings.csv` (checked) + `outputs/tables/FINAL_top10_{bat,bowl}.csv` |
| Pressure balls / matches | `n_h`, `m_h` | FINAL_top10 `n_h`, `m_h` |
| Raw / shrunk / baseline (per 100 balls) | `S_h_raw`, `S_h`, `S_l` | FINAL_top10 (same names) |
| Final rating and 90% bootstrap interval | `final`, `final_p05`, `final_p95` | FINAL_top10 |
| Share of bootstrap resamples in top 10 | `top10_prob` | FINAL_top10 (from `*_bootstrap_summary.csv`, 300 match-level resamples) |
| Median rank, 90% rank range | `rank_median`, `rank_p05`, `rank_p95` | FINAL_top10. **Display rounding:** quantiles are interpolated in the CSV (e.g. 57.2); the site shows whole ranks for the range and the median to 0.1 |
| H / R / C z-scores | `zH`, `zR`, `zC` | FINAL_top10 |
| Contribution of H, R, C (*derived*) | — | `0.60·zH`, `0.25·zR`, `0.15·zC` (sum equals `final`; asserted in `tests/data.test.ts`) |
| Descriptive evidence | `strike_rate_*`, `economy_*`, `dot_pct_*`, `boundary_pct_*`, `dismissals_*`, `wickets_*`, `wides_nb_pct_*` | FINAL_top10 (not scored) |
| Competition / season splits | `n_press_IPL`, `S_raw_IPL`, `n_press_<year>`… | FINAL_top10; shown only with ≥ 24 high-pressure balls |
| Scatter, shrinkage chart (eligible players) | `eligible.json` | `outputs/tables/{bat,bowl}_all_players_base.csv` (`eligible == True`) |
| Sensitivity matrix, overlaps | `sensitivity_lists.json` | `outputs/ranking_results.json` → `grid` (labels, overlap, top-10 lists) |
| Pressure share by innings/phase | `pressure_share.json` | `pressure_share_by_innings_phase.csv` |
| High vs other deliveries | `pressure_validation.json` | `pressure_validation.csv` |
| Win-probability AUC / log-loss / calibration; first-innings projection R², MAE, par | `model.json → wp` | `wp_diagnostics.json` |
| Held-out log-likelihoods | `model.json → chronological` | `chronological_validation.json` |
| τ² estimates (wicket = 0, batter R = 0, bowler R > 0) | `model.json → hyper` | `ranking_results.json → aux` |
| Design effect / ICC | `model.json → se` | `qa/se_design_effect.json` |
| IPL vs T20I | `model.json → fairness` | `ipl_t20i_fairness.json` |
| Season-effect sensitivity | `model.json → season` | `qa/season_sensitivity.json` |
| Persistence (split-half) | `model.json → split_half` | `ranking_results.json → split_half_spearman` |

Notes
- Competition par (172 T20I, 186 IPL) = rounded first-innings means from `wp_diagnostics.json → proj.par`.
- "Stable / Moderately supported / Uncertain" is a *derived* label: stable = top-10 share ≥ 80% and 90% rank range ≤ 25 places; moderate = share ≥ 50%; otherwise uncertain.
- The formula bench (leverage slider) and first-innings gauge on the Pressure section are **illustrations of the formula**, labelled as such; they do not call the model.
- Not used: geographic data (none in the data pack), so no globe/arcs visual.
